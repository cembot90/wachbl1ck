# WACHBL1CK

Müdigkeitserkennung per Webcam. Läuft komplett im Browser auf deinem Rechner,
ohne Konto und ohne Cloud.

- Erkennt Sekundenschlaf und schlägt Alarm
- Müdigkeitsindex aus Lidschlüssen, Gähnen und Kopfhaltung
- Mehrere Monitore einrichten, Fehlalarme lernen
- Themen, Fokusblöcke und Aufmerksamkeitsspanne
- Verlauf speichern, als JSON oder CSV exportieren und wieder einlesen
- Mini-Fenster, das über allen Fenstern liegt
- Farbwelten Blau und Rosa im Design von YEM1N

## Starten

Direkt im Browser: **https://cembot90.github.io/wachbl1ck/** (Chrome oder Edge).
Oder `wachbl1ck.html` herunterladen und öffnen. Mehr dazu, auch zum Start ohne
Verbindung zu Dritten, steht in [LIESMICH.txt](LIESMICH.txt).
